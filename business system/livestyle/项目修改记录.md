# 项目修改记录

## 概述

- **项目名称**: livestyle（直播间样式可视化设计器）
- **架构方案**: 方案B — 分层模块化，Web Components 包装层，BlessStar 配置管理
- **阶段**: Phase 2（IPC 全链路 + 三面板 + TaskList 组件 + 配置架构）
- **修改日期**: 2026-07-11

## 模块结构


## 架构不变量遵循情况

| 不变量 | 描述 | Phase 2 状态 |
|--------|------|-------------|
| **I1** | **画布编辑器与组件运行时引擎必须运行在独立的执行上下文中** | ✅ 组件画板 iframe + engine-bridge iframe 双隔离 |
| **I2** | 组件配置变更必须经过 BlessStar Schema 验证（Phase 2 生效） | ✅ ConfigValidator 已接线 + engine-bridge validateConfig 处理器 |
| **I3** | **组件必须通过 Web Components 标准接口加载** | ✅ TaskList 验证 customElements.define |
| **I4** | 组件配置以独立文件存储 | ✅ component.yaml 独立文件 |
| **I5** | OBS 集成必须是可选的，不得阻塞编辑器主流程 | ⚠️ 未涉及 |
| **I6** | 文件变更（外部编辑）必须触发组件热更新 | ✅ ConfigWatcher (fs.watch + 轮询回退 + 防抖) |
| **I7** | 禁止组件间直接耦合通信 | ✅ TaskList 零依赖 |
| **I8** | **组件 SDK（plugin-sdk）必须零依赖打包** | ✅ TaskList render.ts 仅原生 API |
| **I9** | 图层管理与渲染顺序必须解耦 | ✅ layerStore 独立（Editor 侧持有，Engine 消费结果） |
| **I10** | 配置导出格式必须版本化 | ✅ component.yaml version: 1.0.0 |
| **I11** | **单向数据流：编辑器 → ComponentEngine → 组件实例** | ✅ componentStore → engineClient → TransportAdapter → bridge iframe |
| **I12** | **组件画板必须在独立渲染上下文中运行** | ✅ App.tsx 中 iframe 隔离 |
| **I13** | **属性变更推送必须防抖** | ✅ 300ms debounce |
| **I14** | **TransportAdapter 必须支持连接超时和自动重连** | ✅ 10s 超时 + 重试 3 次 |
| **I15** | config-schema.yaml 为 Codegen 唯一真理源 | ✅ 配管契约已生成 |
| **I16** | Codegen 输出必须通过版本管理 | ✅ 规则已定义 |
| **I17** | 组件画板与主画布通过 IPC 同步，不共享 Store | ✅ iframe 独立运行 |
